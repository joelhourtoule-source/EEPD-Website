IEC 61850 in practice: what to specify before the tender

IEC 61850: architecture, MMS and GOOSE messages, SCL files, testing. What to specify to avoid surprises at commissioning.

By Joël Hourtoule · 4 November 2026

Architecture, messages, SCL files and testing: what to decide before the tender so that an IEC 61850 substation commissions without surprises.

The IEC 61850 series lets a substation’s protection, automation and supervision communicate in a common language, whatever the manufacturer. It reduces cabling between devices and makes upgrades easier. But “IEC 61850 compliant” is not enough to guarantee that devices from different brands work together: this has to be specified and verified.

The three-level architecture

A substation is described in three levels. The station level groups supervision and the gateway to the control centre. The bay level groups the protection and control devices. The process level groups the sensors and switchgear. An Ethernet network links these levels.

Three types of exchange

  • MMS: client-server exchanges between supervision and the devices (reading measurements, commands, alarms)
  • GOOSE: fast messages between devices, for example to pass a trip order or an interlock between protection devices
  • Sampled values: transmission of current and voltage measurements from the process level to the protection devices

SCL files

Substation engineering relies on configuration files in SCL format. The SSD file describes the substation, each ICD file describes the capabilities of a device, the SCD file assembles the system, and each device receives its configuration (CID file). This common format avoids re-entering signals device by device.

What to specify before the tender

  • The Ethernet network architecture: topology, redundancy, separation between station bus and process bus
  • The list of signals, commands and interlocks exchanged between devices
  • Who is the system integrator, and who maintains the SCL files
  • Time synchronisation of the devices
  • The operator’s cybersecurity requirements, with reference to the IEC 62351 series
  • Testing: factory tests with a representative system, interoperability tests between manufacturers, site tests
  • Signal naming rules, common to all suppliers

Common mistakes

Letting each supplier define its own signal names; not appointing anyone responsible for overall engineering; discovering interoperability problems during site tests, when correction costs the most; neglecting maintenance of the SCL files after commissioning, which complicates later changes.

Cybersecurity and operation

A communicating substation is also an IT system. The IEC 62351 series deals with the security of exchanges: authentication, message integrity, access management. Beyond the standard, you must decide who administers the substation network, how device updates are applied and how configurations are backed up. These rules are defined with the operator, before the tender, because they influence the choice of devices and switches.

A step-by-step approach

  • Define the functional need: protection, automation, supervision, interfaces with the control centre
  • Choose the architecture and engineering principles, then record them in the specification
  • Have each supplier validate its device configuration on a common test platform
  • Run factory tests, then site tests, using the signal list as the single reference
  • Document the final state and hand the SCL files over to the operator

Our experience

On ITER, we commissioned the 400 kV substation and the associated HV networks, with communication based on IEC 61850, in 2017–2019. This experience was the subject of a paper: “IEC‑61850‑Based Control System for Power Distribution at ITER” (IEEE Transactions on Plasma Science, 2012).

Frequently asked questions

Does IEC 61850 replace all the cabling?

No: it replaces much of the signalling wiring between devices, but power circuits and some safety circuits remain hard-wired depending on project choices.

Should a single manufacturer be imposed?

Not necessarily. With different manufacturers, however, interoperability must be specified and tested from the factory.

Can an existing substation be upgraded to IEC 61850?

Yes, often in stages: a study of the existing architecture makes it possible to define a migration plan.
